## Hard Constraints
- **STRICT MANUAL MODIFY ONLY (CLIENT MANDATE):** NEVER fire `Modify()`, `Apply()`, or any Tekla 3D model mutation automatically. Ban `DispatcherTimer`, Rx throttle/debounce, `PropertyChanged` hooks, `LostFocus` handlers, or XAML `Delay=` bindings from triggering Tekla `Modify()`. (`DispatcherTimer` is permitted ONLY inside isolated UI-only behavior files for expander hover transitions.)
- **EXPLICIT COMMIT PATH:** Model updates MUST occur ONLY on explicit user action via `WpfOkApplyModifyGetOnOffCancel` or an intentional user-triggered `ModifyCommand` (button click or explicit `Ctrl+M` `KeyBinding`). Live `UpdateSourceTrigger=PropertyChanged` is permitted ONLY for local ViewModel state, inline `INotifyDataErrorInfo` validation, dirty-state tracking, and 2D schematic preview rendering.
- **DIRTY-STATE INDICATOR:** Visually flag uncommitted edits (e.g., accent border or "Modified" badge next to Modify action) so the operator sees when the 2D preview diverges from the 3D Tekla model until manual commit.
- **NET 4.8 & C# VERSION LOCK:** Inspect `.csproj` `<LangVersion>` first. If absent or `7.3`, write strictly C# 7.3 (block-scoped namespaces, explicit `new Type()`, no `record`, no primary constructors, no `[]` collection expressions, no `#nullable enable`, no switch expressions). Never invoke `dotnet build` for `net48` WPF verification, never target `x86`, and never alter Tekla `HintPath` entries.
- **XAML FREEZE SAFETY:** Apply `PresentationOptions:Freeze="True"` ONLY to `Freezable` objects declared in XAML `Resources` (e.g., `StreamGeometry`, `SolidColorBrush`, `Pen`)—NEVER on `<Path>` or other `UIElement` controls. Always ensure root XAML declares `xmlns:mc="http://schemas.openxmlformats.org/markup-compatibility/2006"`, `xmlns:PresentationOptions="http://schemas.microsoft.com/winfx/2006/xaml/presentation/options"`, and `mc:Ignorable="d PresentationOptions"`.
- **NO LEGACY / NO MODALS / NO STRINGLY-TYPED CONTRACTS:** NEVER introduce WinForms (`PluginFormBase`) or `.inp` dialogs. NEVER use blocking `MessageBox.Show()` for validation; use inline `INotifyDataErrorInfo`. NEVER duplicate raw attribute string literals across `[StructuresField]` and `[StructuresDialog]`.
