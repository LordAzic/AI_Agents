# Tekla WPF High-Density UI Rules (.NET Framework 4.8)

## 1. Parameter-to-Control Decision Matrix
| Complexity | Spatial Dependency | Mandatory Control |
| :--- | :--- | :--- |
| **Low** (Material, Class, Phase, Prefix) | Independent | Compact Controls (`ComboBox`, Segmented Toggle, Tekla Color Swatch) |
| **Medium** (Bolt Pitch, Uniform Weld) | Semi-Dependent | Compact Micro-Grid / Icon-Button Group |
| **High** (Haunches, Copes, Asymmetric Chamfers) | Highly Dependent | 2D Vector Schematic (`Canvas`) + Dynamic Callouts (`tekla-2d-preview`) |

## 2. Cognitive Load, Progressive Disclosure & Tab Architecture
- **Coupled Geometry Rule:** Ban multi-tab pagination for coupled geometric parameters (prevents Split-Attention Effect). Keep all active categorized vertical expanders and the 2D preview together on **Tab 1**.
- **Autogenerated `StructuresField` Tab (Mandatory Tab 2):** Preserve a dedicated `StructuresField` tab listing **all** declared `StructuresData` attributes as a raw engineering override. Never prune fields from Tab 2, even when `tekla-model-param-audit` omits them from Tab 1.
- **Summary Badge Expanders:**
  - Header shows 2-3 identifying variables in engineering shorthand (e.g., `Bolts: 4x M20 Gr8.8 | Pitch: 60`, `PL 10x200`).
  - Reflect state visually (muted opacity = disabled; red outline = fabrication tolerance violation).
  - Entire badge header acts as click/hover hit target.

## 3. Responsive Layout & Sidebar Mode (#2)
- **No Wide Minimum Lock:** Remove wide `MinWidth` constraints on `PluginWindowBase`. Set a practical floor equal to the collapsed vertical sidebar width (`40–60 px`) to prevent WPF layout thrashing.
- **Auto-Collapse to Sidebar:** Monitor `Window.SizeChanged`. When `Available2DWidth < ExpanderPanelWidth`, set the 2D preview container to `Visibility.Collapsed` so the UI collapses into a compact vertical sidebar menu.
- **Hysteresis Deadband:** Apply a `±15 px` hysteresis buffer around the collapse threshold so the 2D preview never flickers on/off during edge resizing.

## 4. Smart Property Search & Batch Setter (#3)
- Provide a top-level autocomplete search bar supporting comma-separated `Name = Value` batch edits (local ViewModel + 2D preview ONLY—never auto-fire `Modify()`), with edit-distance typo guard. Load `references/xaml-blueprints.md` for tokenization and popup wiring.


## 5. Interactive Vertical Expander Controls & Behaviours (#4, #6, #8)
- **Right-Click Quick Collapse (#4):** Right-clicking (`PreviewMouseRightButtonUp`) anywhere inside an open vertical expander collapses it—EXCEPT when `e.OriginalSource` is inside an interactive control (`TextBox`, `Button`, `ToggleButton`, `ComboBox`, `Slider`, or color swatch). Before setting `IsExpanded = false`, force `BindingExpression.UpdateSource()` / `Keyboard.ClearFocus()` so active edits always commit first.
- **Timed Hover Expand / Collapse (#8):**
  - Hovering over a vertical expander header expands it after **`200 ms`**.
  - Moving the cursor outside both header and content area collapses it after **`300 ms`**.
  - **Hard Interlock:** Suppress the `300 ms` collapse timer whenever any child control holds keyboard focus (`IsKeyboardFocusWithin == true`) OR a child `Popup`/`ComboBox` (such as the Tekla color palette) is open. Resume timer only after focus clears and popups close.
  - Isolate hover `DispatcherTimer` logic in a dedicated attached-behavior `.cs` file with zero Tekla `Modify()`/`Apply()` references.
- **Colours Vertical Expander (#6):**
  - Display the Tekla color enum number alongside a clickable `Border` swatch showing the actual RGB color.
  - Clicking the swatch opens a `Popup` palette of Tekla's built-in colors (mapped via centralized `TeklaColorPalette` lookup). Selecting a color updates the enum integer, swatch brush, and live 2D preview simultaneously.

## 6. KLM-GOMS, Fitts's Law & Explicit Manual Commit
- **Hit Area Expansion:** Expand callout `TextBox` hit areas via `Padding="4" Margin="-4"` on wrapping `Border` to lower Fitts target acquisition time ($T = a + b \log_2(2D/W)$).
- **Keyboard-First Chaining:** Explicitly map `TabIndex` around the geometric perimeter of the 2D schematic.
- **Zero-Homing Input:** Attach `MouseWheel` increment/decrement behaviors (e.g., 5mm general, 1mm precise tolerance) to numeric fields.
- **Native Unit Parsing:** Bind distance properties to Tekla `TD.Distance` struct so Metric and Imperial inputs parse natively without user mental conversion.
- **Explicit Manual Commit Only (Client Rule):** NEVER debounce or auto-fire Tekla `Modify()`. Use `UpdateSourceTrigger=PropertyChanged` strictly for instant 2D schematic preview, dirty-state tracking, and inline validation. Commit to the 3D Tekla model ONLY via explicit user click (`WpfOkApplyModifyGetOnOffCancel`) or intentional `Ctrl+M` `KeyBinding`.

## 7. Pixel-Perfect WPF Rendering & Visual Tree Optimization
- Root `PluginWindowBase` & parameter grids: `UseLayoutRounding="True"` and `SnapsToDevicePixels="True"`.
- Dense numeric text (9-11pt): `TextOptions.TextFormattingMode="Display"` and `RenderOptions.ClearTypeHint="Enabled"`.
- Orthogonal 2D schematic `Canvas`: `RenderOptions.EdgeMode="Aliased"`.
- Static vectors: Prefer `StreamGeometry` over `PathGeometry`. Declare frozen `StreamGeometry` and `SolidColorBrush` resources in `Window.Resources` / `UserControl.Resources` with `PresentationOptions:Freeze="True"` (or call `.Freeze()` in C#), and reference them via `{StaticResource ...}` on `<Path>`. NEVER place `PresentationOptions:Freeze="True"` directly on `<Path>` (not a `Freezable`).
- Ultra-dense vectors (1,000+ elements such as rebar meshes): Override `FrameworkElement.OnRender` using `DrawingContext` / `DrawingVisual`.
- Micro-interactions: Complete state transitions in `< 150ms` using `DoubleAnimation` + `CubicEase`.

## 8. Tekla Open API & .NET 4.8 Binding Safety
- Centralize all Tekla attribute keys in `public static class AttributeNames` (`public const string`).
- Reference constants identically in `[StructuresField(AttributeNames.X)]`, `[StructuresDialog(AttributeNames.X, typeof(...))]`, and `tekla:WpfFilterCheckBox` (`{x:Static local:AttributeNames.X}`).
- Implement `INotifyDataErrorInfo` for non-modal inline validation.
- Default to C# 7.3 syntax unless `.csproj` explicitly specifies a higher `<LangVersion>`. Build exclusively via Visual Studio `MSBuild.exe` targeting `x64`.
